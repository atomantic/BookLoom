### Promotional Text

Plan your next book club pick with shared proposals, ranked voting, meetings, RSVPs, reminders, notes, and discussion prompts.

### Description

BookLoom helps private reading groups choose the next book, plan meetings, and keep the conversation in one shared place.

Create a club for your group, invite members with iCloud sharing, and collect every suggestion before the next vote. When it is time to choose, run a ranked poll or pick from the proposal list, then keep the current read, meeting details, RSVPs, reminders, ratings, notes, and discussion prompts together.

Use BookLoom to:

- Create private book clubs synced with iCloud
- Add book proposals with cover and metadata lookup
- Run ranked votes for the next read
- Schedule meetings with hosts, locations, links, RSVPs, agendas, and reminders
- Save star ratings, notes, and discussion prompts for each book
- Keep completed reads and past meetings in your club history

BookLoom is built for small book clubs that already know each other. It does not include public club discovery, ads, paid club dues, or a social feed.
