### Promotional Text

Plan your next book club pick with shared proposals, ranked voting, meetings, RSVPs, reminders, notes, and discussion prompts.

### Description

PlotLoom helps private reading groups choose the next book, plan meetings, and keep the conversation in one shared place.

Create a club for your group, invite members with iCloud sharing, and collect every suggestion before the next vote. When it is time to choose, run a ranked poll or pick from the proposal list, then keep the current read, meeting details, RSVPs, reminders, ratings, notes, and discussion prompts together.

Use PlotLoom to:

- Create private book clubs synced with iCloud
- Add book proposals with cover and metadata lookup
- Run ranked votes for the next read
- Schedule meetings with hosts, locations, links, RSVPs, agendas, and reminders
- Save star ratings, notes, and discussion prompts for each book
- Keep completed reads and past meetings in your club history

PlotLoom is built for small book clubs that already know each other. It does not include public club discovery, ads, paid club dues, or a social feed.

## App Review Information

- Sign-in required: `No`
- Demo account: `Not applicable`
- Review notes:

PlotLoom does not require a separate app account. To test, enter any display name, create a club, add book proposals, start a ranked poll, and schedule a meeting. iCloud sharing uses Apple's CloudKit sharing flow and requires the reviewer device to be signed in to iCloud.

## Privacy And Safety Notes

- No public social feed.
- No public club discovery.
- No ads.
- No in-app purchases currently.
- No app-managed passwords or external account registration.
- User-entered display names, book proposals, ratings, notes, meeting details, RSVPs, and discussion prompts sync through the user's iCloud/CloudKit account when sharing or sync is enabled.
- The app may contact book metadata providers when the user searches for cover/details from the Add Book flow.
